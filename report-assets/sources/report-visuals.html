Stakeholder and Requirement Map

Repository-derived analysis; external survey responses have not yet been collected

Agent user

  • Safe completion with understandable denials
  • Low approval burden and useful alternatives
  • No credential exposure in model context

System operator

  • Authenticated identities and durable administration
  • Exact coverage gaps and health diagnostics
  • Recovery, rollback and audit evidence

Security reviewer

  • Representation-invariant policy
  • Replay, concurrency and bypass resistance
  • Traceable claims linked to reproducible tests

MCP server owner

  • Stable schema and route registration
  • Audience-bound credentials
  • Clear quarantine and re-review workflow
